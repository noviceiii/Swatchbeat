# Swatchbeat — Web

Standalone page: live `@beat` clock plus Clock ↔ Beat converters.

## Run

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080

## Live reference

The Creabyte-hosted version (with site branding):  
https://www.creabyte.com/swatchbeat

## Files

- `index.html` — page
- `style.css` — neutral styles
- `swatchbeat.js` — beat math + UI
